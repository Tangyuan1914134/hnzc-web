# hnzc-web

河南紫宸信息服务有限公司静态企业站，适配 GitHub Pages 与自定义域名。

## 页面

- `index.html`：首页
- `about.html`：公司介绍
- `services.html`：业务服务
- `cases.html`：场景参考
- `contact.html`：联系我们
- `admin.html`：浏览器本地内容编辑器
- `404.html`：未找到页面

## 本地编辑器

打开 `admin.html`，首次使用时设置当前浏览器的本机密码。修改内容后需点击“保存当前页”；数据仅保存在浏览器 `localStorage`，不会自动写回 GitHub 仓库。可通过导出/导入 JSON 迁移配置。

## 部署

仓库根目录可直接由 GitHub Pages 发布，不需要构建步骤。`CNAME` 当前指向 `hnzc.tangyuan1349.top`。
